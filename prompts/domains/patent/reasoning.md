# Patent Reasoning Framework (IRAC)

特許侵害訴訟の分析には IRAC フレームワークを適用する。

## I - Issue（争点の特定）

以下を明確にする：
- 原告の請求内容（差止・損害賠償・その両方）
- 対象特許権（特許番号、請求項）
- 被告製品/方法の特定
- 当事者間の主要な争点

**争点の類型:**
- 技術的範囲の属否（文言侵害・均等侵害）
- 間接侵害の成否
- 無効の抗弁の成否
- 損害額の算定

## R - Rule（適用法規・判断基準）

争点ごとに適用される：
- 条文（特許法70条、100条、101条、102条、104条の3等）
- 判例法理（均等論、包袋禁反言等）
- クレーム解釈の基準

## A - Analysis（分析）

### 構成要件対比
クレームを構成要件に分説し、被告製品と対比する：

```
構成要件A: [クレーム文言]
  ↓ 対比
被告製品: [対応構成]
  ↓ 判断
充足/非充足: [理由]
```

### 均等論の検討（文言非充足の場合）
5要件それぞれについて検討する。

### 無効の抗弁の検討（主張された場合）
- 無効理由（新規性欠如、進歩性欠如等）
- 主引例・副引例の認定
- 相違点と容易想到性

## C - Conclusion（結論）

- 侵害の成否
- 損害額（認容された場合）
- 判決の射程・実務への影響
