# Patent Domain Knowledge

## 基本法令

### 特許法70条（技術的範囲）
特許発明の技術的範囲は、願書に添付した特許請求の範囲の記載に基づいて定めなければならない。
- 明細書・図面は参酌されるが、請求項が基準
- 出願経過も考慮される（包袋禁反言）

### 特許法100条（差止請求権）
特許権者は、侵害者に対し、侵害の停止・予防を請求できる。

### 特許法101条（間接侵害）
以下は特許権の侵害とみなす：
- 専用品の生産・譲渡等
- 発明の課題解決に不可欠な物の供給（悪意）

### 特許法102条（損害額の推定）
- 1項：侵害品の譲渡数量 × 権利者の単位利益
- 2項：侵害者の利益額
- 3項：実施料相当額

### 特許法104条の3（無効の抗弁）
特許が無効審判により無効にされるべきものと認められるときは、権利行使不可。

## 侵害判断の階層

```
1. 文言侵害
   └─ クレームの文言に直接該当するか
         ↓ 非該当
2. 均等侵害
   └─ 均等論5要件を全て充足するか
         ↓ 非該当
3. 間接侵害
   └─ 101条各号に該当するか
```

## 均等論5要件（ボールスプライン最判 H10.2.24）

| 要件 | 内容 | 立証責任 |
|------|------|----------|
| 1. 非本質的部分 | 相違部分が発明の本質的部分でない | 原告 |
| 2. 置換可能性 | 置換しても同一の作用効果を奏する | 原告 |
| 3. 置換容易性 | 当業者が容易に想到できた | 原告 |
| 4. 非公知技術 | 出願時の公知技術と同一・容易推考でない | 被告 |
| 5. 意識的除外なし | 出願経過で意識的に除外されていない | 被告 |

## クレーム解釈の原則

- **明細書参酌**: 請求項の用語は明細書の記載を参酌して解釈
- **出願経過参酌**: 補正・意見書の内容も考慮
- **発明の目的・効果**: 発明の技術的意義に照らして解釈
- **公知技術の参酌**: 公知技術を含まないように解釈（権利範囲の制限）
